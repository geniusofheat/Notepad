This is your Notepad home screen — your lists live here. Use [ new list + ] to start a new list, and [ sync + ] to link this device with another one so your notes stay the same everywhere. Tap a list title to open or close it, then [ add note + ] to add a note inside it. Tap any note title to open it for writing and formatting. Tap [ edit ], then a title, to rename it.
